To use this module:

  1. Go to **Invoicing → Configuration → Chart of Accounts**.
2. Click **Create** to create a new account.
3. Enter the **Account Name**.
4. Select the **Account Type**.
5. Leave the **Code** field empty.
6. Save the record.

The system will automatically generate the next available account code based
on the selected account type.

Example:

Account Type: Expense
Generated Code: 5001
