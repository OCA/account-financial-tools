This module automatically generates the next available account code for
the Chart of Accounts based on the selected Account Type.

When creating a new account without specifying a code, the system
determines the appropriate sequence based on the account type (Asset,
Liability, Equity, Income, Expense, etc.) and assigns the next available
code.

This helps maintain a structured and consistent numbering system for the
Chart of Accounts and reduces manual errors during account creation.

Configuration
=============

The system will automatically generate the next account code when
creating a new account.

Usage
=====

To use this module:

1. Go to **Invoicing → Configuration → Chart of Accounts**.
2. Click **Create** to create a new account.
3. Enter the **Account Name**.
4. Select the **Account Type**.
5. Leave the **Code** field empty.
6. Save the record.

The system will automatically generate the next available account code
based on the selected account type.

Example:

Account Type: Expense Generated Code: 5001
