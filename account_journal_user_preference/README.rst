Configure an ordered list of preferred journals for each internal user.
Eligible preferred journals are returned before other journals when
using the default search order, including journal dropdowns and default
journal selection on accounting documents.

The original search domains, company restrictions and access rules still
apply. Preferences do not make an otherwise unavailable journal
selectable. An explicit custom search order takes precedence over user
preferences.

Configuration
=============

No additional configuration is required after installing the module.
Users with invoicing or accounting read access can configure their own
journal preferences.

Usage
=====

- Open the user menu and select Preferences.
- Open the Personalization tab.
- Enable Prioritize Preferred Journals.
- Add journals under Preferred Journals and drag the sequence handles to
  arrange them in priority order.
- Save the preferences.

Disable Prioritize Preferred Journals to restore the standard search
order without deleting the configured preferences. The journal table
remains read-only until preferences are enabled again.

For example, a customer invoice still only offers eligible sales
journals. Preferred sales journals appear first; preferred purchase or
miscellaneous journals are excluded by the invoice's standard domain.

Known issues / Roadmap
======================

Preference ordering also applies when a caller explicitly requests the
model's default order. Odoo 18 passes that order internally for ordinary
searches and dropdowns.

Applying preferences materializes all eligible journals before
pagination. This approach is intended for ordinary journal lists, rather
than very large journal datasets.
