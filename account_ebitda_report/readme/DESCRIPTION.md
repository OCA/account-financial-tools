This module provides a Professional EBITDA financial report in Odoo
using MIS Builder. It transforms standard accounting data into an
advanced Corporate Finance and M&A reporting tool.

Key features include:

- Three calculation methods: Bottom-Up, Top-Down, and Professional
  (Adjusted).
- Calculation of EBITDA Margin (%).
- Calculation of Adjusted EBITDA by isolating extraordinary
  income/expenses and M&A adjustments (e.g. Owner Salary, Personal
  Expenses).
- Calculation of Net Financial Debt and Debt / EBITDA Ratio.
- A complete bridge from EBITDA to Free Cash Flow (FCF) through Working
  Capital variations and CAPEX.
