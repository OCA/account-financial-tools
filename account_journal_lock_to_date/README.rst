Lock each accounting journal independently from a given date onwards.

This module provides a 'Lock To Date' and a 'Lock To Date for
Non-Advisers' per journal. Journal entries dated on or after these dates
cannot be posted, modified, reset to draft or cancelled. This allows,
for instance, to prevent entries from being recorded in the future in
some journals only.

This module also adds a wizard that allows you to update the 'Lock To
Date' and the 'Lock To Date for Non-Advisers' for several journals at
the same time.

Configuration
=============

To configure this module, you need to:

1. Go to *Invoicing > Configuration > Journals*
2. Open a Journal and set the 'Lock To Date' and the 'Lock To Date for
   Non-Advisers' in the 'Advanced Settings' tab of the form view or
   select several Journals in the list view and click on the action menu
   'Update journals lock to dates' to update those dates for the
   selected journals at the same time.

Usage
=====

If the logged-in user has the access group 'Adviser', he/she will not be
able to create or modify a journal entry dated on or after the 'Lock To
Date' of its journal.

If the logged-in user does not have the access group 'Adviser', he/she
will not be able to create or modify a journal entry dated on or after
the earliest of the 'Lock To Date' and the 'Lock To Date for
Non-Advisers' of its journal.

The check can be bypassed programmatically with the
``bypass_journal_lock_to_date`` context key.
