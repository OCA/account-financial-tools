Lock each account independently from a given date onwards.

This module adds a 'Lock To Date' on accounts, tracked in their chatter.
Journal entries using an account and dated on or after its lock to date
(included) cannot be posted, modified, reset to draft or cancelled. This
allows, for instance, to stop using an account from a given date, e.g.
when it is replaced by another one.

This module also adds a wizard that allows you to update the 'Lock To
Date' of several accounts at the same time.

Configuration
=============

To configure this module, you need to:

1. Go to *Invoicing > Configuration > Chart of Accounts*
2. Open an account and set its 'Lock To Date', or select several
   accounts in the list view and click on the action menu 'Update
   accounts lock to dates' to update this date for the selected accounts
   at the same time (only for users with the 'Adviser' role).

Usage
=====

A journal entry dated on or after the 'Lock To Date' of one of the
accounts used on its lines cannot be posted, modified, reset to draft or
cancelled.

The check can be bypassed programmatically with the standard
``bypass_lock_check`` context key set to ``BYPASS_LOCK_CHECK``.
