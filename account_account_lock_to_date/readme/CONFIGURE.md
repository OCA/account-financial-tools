To configure this module, you need to:

1.  Go to *Invoicing \> Configuration \> Chart of Accounts*
2.  Open an account and set its 'Lock To Date', or select several
    accounts in the list view and click on the action menu 'Update
    accounts lock to dates' to update this date for the selected
    accounts at the same time (only for users with the 'Adviser' role).
