To set new lock to dates, go to *Invoicing / Accounting / Actions /
Update accounting lock to dates*.

* **Global Lock To Date / Sales Lock To Date / Purchase Lock To Date**: Soft locks
  that prevent posting on or after the defined date, unless an active lock exception
  (`account.lock_exception`) is granted.

* **Hard Lock To Date**: Strict lock that prevents posting on or after the defined date
  for all users without exception.
