This module introduces a customized Accounting Dashboard kanban view. It
provides a cleaner interface by hiding default graphs and adds new
functionalities:

Main features:

- A unified dropdown for balance details (Balance, Latest Statement,
  Outstanding Payments, Misc. Operations).
- Direct "Reconcile" action access and a badge for items to reconcile.
- "Upload Bills" functionality in the purchase journal.
- Improved layout by removing the default kanban styling class when
  accessed via the custom dashboard menu.

Configuration
=============

No specific configuration is required. The dashboard inherits the
standard journals and applies its logic automatically when accessed via
the "Accounting Dashboard" menu.

Usage
=====

To use this module:

1. Go to **Accounting → Accounting Dashboard** (or **Invoicing →
   Accounting Dashboard**).
2. The custom kanban view for journals will be displayed.
3. For bank and cash journals, you can use the "Balance Details"
   dropdown to view balances, past statements, outstanding payments, and
   misc operations.
4. You will see a quick "Rec [N] Items" button if there are items to
   reconcile.
5. In the Purchase journal, you can use the "Upload Bills" button
   directly from the kanban card.
