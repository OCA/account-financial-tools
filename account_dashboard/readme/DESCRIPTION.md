This module introduces a customized Accounting Dashboard kanban view. It provides a cleaner interface by hiding default graphs and adds new functionalities:

Main features:

- A unified dropdown for balance details (Balance, Latest Statement, Outstanding Payments, Misc. Operations).
- Direct "Reconcile" action access and a badge for items to reconcile.
- "Upload Bills" functionality in the purchase journal.
- Improved layout by removing the default kanban styling class when accessed via the custom dashboard menu.
