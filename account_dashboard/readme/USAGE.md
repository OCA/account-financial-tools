To use this module:

1. Go to **Accounting → Accounting Dashboard** (or **Invoicing → Accounting Dashboard**).
2. The custom kanban view for journals will be displayed.
3. For bank and cash journals, you can use the "Balance Details" dropdown to view balances, past statements, outstanding payments, and misc operations.
4. You will see a quick "Rec [N] Items" button if there are items to reconcile.
5. In the Purchase journal, you can use the "Upload Bills" button directly from the kanban card.
