This module adds an independent entry review step on posted journal entries,
invoices, vendor bills, and payments:

- Dedicated *Entry Reviewer* security group outside the Accounting category
  (implies Accounting Manager without being granted to regular accountants).
- Optional per-company setting to restrict *Reset to Draft* on posted moves and
  payments to reviewers.
- One-click *Mark Reviewed* action (single and list batch) with no notification noise.
- Reset-to-draft wizard with optional notes and direct chatter notification to the
  entry creator.
- Optional *Document Type* classification (`Documentary` / `Non-Documentary`) editable
  on draft and posted entries.
- Persistent filters and grouping across moves, invoices, journal items, and payments.
