This module will add the sale order line to stock journal items created
for a repair order.

This is kind of glue module between account_move_line_sale_info and
repair

**Table of contents**

.. contents::
   :local:

Usage
=====

The sale order line will be automatically copied to the journal items
when a quotation is created from a repair order no matter if the
quotation is created before adding the moves or not.
