Go to *Invoicing / Accounting > Configuration > Settings > Chart of
Accounts* and set:

- *Lock code of used accounts*: forbid changing the code of an account
  used in posted journal entries.
- *Check account label uniqueness*: forbid two accounts sharing a company
  from having the same label (case insensitive, in the language of the
  user). The option cannot be enabled while duplicated labels exist: the
  duplicates are listed instead.
- *Require a modification reason*: require a reason to modify an account.

All the options are disabled by default.

Configure the modification reasons in *Invoicing / Accounting >
Configuration > Accounting > Account Modification Reasons*.
