This module provides functionality to spread costs and revenues over a specified period while respecting lock dates. Below are the steps to use this module effectively:

1. Navigate to the module's settings and configure the necessary parameters, such as lock dates and default accounts.
2. Go to the "Invoicing > Accounting > Spread Costs/Revenues" menu, create a new spread board.
3. Fill in the necessary details such as the name, amount, and period for spreading.
4. click Recalculate unposted lines for create Spread lines.
5. Go to the "Settings > Technical > Scheduled Actions" menu and looking for Cost/revenue Spread: Create Entries.
6. click Run manually to create the entries for the spread lines.
7. Navigate to the "Spread Lines" to review the generated entries.
8. You will see entries on the spread lines with before lock date won't be created.
