Optional wizard flag to update tax repartition lines in-place when
posted move lines reference them, avoiding the OCA ``(5, 0, 0)``
delete/recreate that triggers PostgreSQL RESTRICT on
``account_move_line.tax_repartition_line_id``.

Installation
============

To use this module you need:

1. The **account_chart_update** module (from OCA
   account-financial-tools).
2. Optionally, **account_chart_update_code_digits** for code digit
   validation.

Configuration
=============

No special configuration needed. The module adds a checkbox to the
existing chart update wizard.

Usage
=====

1. Go to *Accounting > Configuration > Update chart template*.
2. Enable *Update taxes*.
3. Check *Update tax repartition preserving posted moves*.
4. Click *Find records* and then *Apply*.

When the checkbox is off, behaviour is identical to OCA
``account_chart_update``.

Known issues / Roadmap
======================

- Does not rewrite ``account_id`` on historical ``account.move.line``
  rows.
- Unmatched repartition lines referenced by posted entries are kept and
  logged.
